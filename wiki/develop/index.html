Develop

This section is for anyone working on walle itself: the CLI, the modules it ships, the repo layout, and the suites that gate a change.

  • Repo guide: the three zones of this repository and where a change belongs.
  • CLI reference: every cli.sh command, flag and error.
  • Managed vs seed: the two file classes every shipped path belongs to, and the full per-module breakdown.
  • Astrobook: the component catalog for developing and visually gating components.
  • Testing: every suite, what it covers, and the exact command to run it.
  • Versioning: the release process and tag policy.

If you are consuming walle in a site rather than developing it, start at Get Started instead.
